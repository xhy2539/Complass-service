# 规则库数据库字段说明

规则库来源：`rules.csv`，当前 59 条。建议表名：`review_rules`。

| 字段名 | 类型建议 | 必填 | 说明 |
|---|---|---|---|
| `id` | bigint | 是 | 主键，自增 |
| `rule_code` | varchar(50) | 是 | 规则编号，唯一，如 `COM-FIN-001` |
| `contract_type` | varchar(50) | 是 | 合同类型，如通用、采购合同、服务合同 |
| `review_module` | varchar(50) | 是 | 审核模块，如财务、法务、履约 |
| `risk_name` | varchar(100) | 是 | 风险名称 |
| `check_point` | text | 否 | 检查点，说明审核什么 |
| `trigger_condition` | text | 否 | 触发条件，说明何时命中风险 |
| `default_risk_level` | varchar(20) | 是 | 默认风险等级：高、中、低 |
| `suggestion_template` | text | 否 | 修改建议模板 |
| `example_clause` | text | 否 | 示例问题条款 |
| `enabled` | boolean | 是 | 是否启用，默认 `true` |
| `created_at` | datetime | 是 | 创建时间 |
| `updated_at` | datetime | 是 | 更新时间 |

约束：

- `rule_code` 唯一且必填。
- `contract_type`、`review_module`、`risk_name`、`default_risk_level` 必填。
- `default_risk_level` 只允许：`高`、`中`、`低`。
