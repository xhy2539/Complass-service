# Complass-service

`Complass-service` 是“合规罗盘”项目的后端服务仓库，负责提供业务接口、规则处理与服务集成能力。

## 项目简介

本仓库当前处于初始化阶段，核心目标是先打通团队协作与工程化流程，再逐步补齐业务模块。  
当前已完成基础代码仓库管理与 CI 接入，后续将围绕合规业务能力持续迭代。

## 项目目标

1. 提供稳定、可维护的后端服务能力。
2. 支持合规相关数据处理与规则执行。
3. 建立标准化开发流程（分支、评审、持续集成）。

## 当前状态

- 代码基础：初始化阶段（业务代码待补充）。
- 工程化：已接入 Gerrit + Jenkins，具备基础流水线能力。
- 协作方式：通过 Gerrit 进行评审与合并。

## 仓库结构

- `Jenkinsfile`：项目 CI 流水线定义。
- `README.md`：项目说明文档。

## 开发与协作流程

1. 在本地 `dev` 分支开发并提交。
2. 推送到 `refs/for/dev` 发起评审。
3. 评审通过后由具备权限的成员完成提交合并。
4. 合并前需通过 Jenkins `Verified` 检查。

## CI 简要说明

Jenkins Job：`Complass-service`  
流水线入口：仓库根目录 `Jenkinsfile`

流水线会根据项目实际构建文件自动识别 Maven/Gradle/Python；在初始化阶段没有构建文件或检出失败时，执行基础引导检查（Smoke Check），确保 CI 链路可用。
